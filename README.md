# tutor-courses

A community collection of courses built on the [tutor](https://github.com/open-smarty/tutor) template. Each course is a self-paced learning experience that works in VS Code, as a hosted GitHub Pages site, or as a single offline HTML file.

---

## Contributing a course

1. Fork this repo
2. Run `npm run add-course -- your-topic "Your Course Title"`
3. Fill in the three files it creates under `courses/your-topic/_teacher/`
4. Drop any supporting materials into `courses/your-topic/_teacher/resources/` (slides, syllabuses, past exam questions, datasets, etc.)
5. Open Claude Code in this folder and say: **"create the course for your-topic"**
6. Submit a pull request

That's it. Claude reads your teacher notes and generates the full lesson content, quizzes, and exercises.

---

## Two ways to use the tutor template

### This repo — multi-course hub

Use this repo when you want to publish multiple courses in one place. Each course lives under `courses/<slug>/`. A shared base template is maintained as a git subtree and updated independently of the courses.

### Standalone fork

If you only need one course, [fork the tutor template directly](https://github.com/open-smarty/tutor). Fill in `_teacher/`, open Claude Code, say "create the course." Done.

## Commands

```bash
# One-time setup (installs base dependencies)
npm run install-base

# Add a new course scaffold
npm run add-course -- <slug> "Course Title"

# List all courses and their status
npm run list-courses

# Preview a course in the browser while building it
npm run dev -- <slug>

# Check a lesson (runs the grader)
npm run check -- <slug> <module-id> <lesson-id>

# Build a single course as an offline HTML file → dist/<slug>/index.html
npm run build-course -- <slug>

# Build every course + landing page → dist/
npm run build

# Pull the latest tutor template changes into base/
npm run update-base
```

## GitHub Pages

Every push to `main` triggers a build of all generated courses and deploys them to GitHub Pages.

To enable it:

1. Go to your fork on GitHub → **Settings → Pages**
2. Under **Source**, select **GitHub Actions**
3. Push any change to `main`

The landing page at your Pages URL lists every course with a link to its viewer.

## Repo layout

```
tutor-courses/
  base/                        ← tutor template (git subtree — do not edit directly)
  courses/
    <slug>/
      _teacher/                ← fill these in; Claude reads them to generate the course
        course-description.md
        requirements.md
        grading-policy.md
        resources/             ← slides, syllabuses, past questions, datasets, etc.
      _course/                 ← generated by Claude; do not edit by hand
      _assessments/            ← generated by Claude; do not edit by hand
  scripts/                     ← repo tooling
  .github/workflows/deploy.yml ← CI build + Pages deploy
```

---

## Updating the base template

When the tutor template is updated, pull the changes into `base/`:

```bash
npm run update-base
```

This rebases `base/` from the upstream tutor repo without touching any course content.
