# Tutor

> A repo-based self-paced learning system. Teachers generate a complete course with Claude Code. Students access it in whatever way suits them — locally with full interactivity, via a hosted URL, or as a single offline file.

## How it works

```
Teacher fills course description
        ↓
Claude Code generates the full course
(lessons, exercises, quizzes, tasks, rubrics)
        ↓
Teacher chooses how to distribute ──────────────────────────────┐
                                                                 │
┌────────────────────┬──────────────────────┬───────────────────┴──────┐
│  VS Code           │  GitHub Pages        │  Static file             │
│  + Live Server     │  (hosted URL)        │  (offline)               │
│                    │                      │                          │
│  Full features:    │  Visit a URL.        │  Double-click the file.  │
│  checks, Claude    │  No setup.           │  Works anywhere.         │
│  clarifications,   │  Auto-deploys on     │  No internet needed      │
│  progress saving   │  git push            │  after download          │
└────────────────────┴──────────────────────┴──────────────────────────┘
```

## For teachers

### Requirements

- [VS Code](https://code.visualstudio.com/)
- [Claude Code](https://claude.ai/code) — required for course generation

### Build the course

1. Clone or download this base repo
2. Run the setup script (installs Node.js and VS Code extensions automatically):
   - **Windows:** double-click `setup.bat`
   - **Mac / Linux:** `bash setup.sh`
3. Fill in `_teacher/course-description.md`
4. Fill in `_teacher/requirements.md`
5. Drop any existing materials into `_teacher/resources/` (optional but recommended):
   - `slides/` — lecture slides (PDF or images)
   - `past-questions/` — past exams or quiz banks
   - `exercises/` — existing worksheets
   - `readings/` — textbook excerpts or references
   - `datasets/` — data files for exercises
   - `syllabus/` — existing syllabus or topic list
6. Open Claude Code and run:
   ```
   Create the course from the description
   ```
6. Review and edit the generated content
7. Test by opening `index.html` with Live Server

### Distribute the course

Pick one or more distribution modes:

#### Mode 1 — VS Code (full features)

```bash
npm run export        # packages the course as a .zip
```

Students unzip, run the setup script, and open `index.html` with Live Server.
Full feature set: lesson checks, progress saving, Claude Code clarifications.

#### Mode 2 — GitHub Pages (hosted URL)

Push this repo to GitHub. Then:

1. Go to **Settings → Pages**
2. Under **Source**, select **GitHub Actions**
3. Push any change to `main` — the site deploys automatically

The workflow at `.github/workflows/deploy.yml` runs `npm run build` and deploys `dist/` to your Pages URL. Every push to `main` triggers a fresh deploy.

#### Mode 3 — Static file (offline / shareable)

```bash
npm run build         # generates dist/index.html
```

Send `dist/index.html` to students as a file attachment, USB stick, or shared drive.
Opens in any browser without a server. Works completely offline.
Quizzes and progress tracking (via localStorage) still work.

> Run `npm run build` again whenever you update lesson content or clarifications.

## For students

### Option A — You received a zip file (VS Code)

1. Unzip the course folder
2. Run the setup script:
   - **Windows:** double-click `setup.bat`
   - **Mac / Linux:** `bash setup.sh`
3. Open `index.html` via Live Server: right-click → **Open with Live Server**

### Option B — You have a URL (GitHub Pages)

Visit the link your teacher sent. Nothing to install.

### Option C — You received an HTML file (offline)

Double-click `index.html`. It opens in your browser. No setup needed.

### Getting help while studying

If you have Claude Code, open the terminal in VS Code and paste the prompt shown at the bottom of each lesson. Claude will explain the concept and save a note into the course — visible to all students.

## Folder structure

```
tutor/
├── index.html                   ← Student entry point (VS Code mode)
├── setup.bat                    ← Windows one-click setup
├── setup.sh                     ← Mac/Linux one-click setup
├── CLAUDE.md                    ← AI tutor instructions
│
├── _course/
│   ├── course.json              ← Course structure (generated by Claude Code)
│   ├── lessons/                 ← One folder per lesson
│   └── clarifications/          ← Student questions → saved explanations
│
├── _assessments/
│   ├── quizzes/                 ← Per-lesson quiz JSON files
│   ├── tasks/                   ← Per-lesson task descriptions
│   └── rubrics/                 ← Project grading rubrics
│
├── _tools/
│   ├── builder/                 ← Static site generator (npm run build)
│   ├── exporter/                ← Zip packager (npm run export)
│   ├── grader/                  ← Lesson checker (npm run check)
│   ├── preview/                 ← Local preview server (npm start)
│   └── progress/                ← Progress summary (npm run progress)
│
├── _assets/                     ← Images, datasets, diagrams
├── _teacher/                    ← Course description, requirements, grading policy
│
├── dist/                        ← Build output (git-ignored, deployed to Pages)
└── .github/workflows/
    └── deploy.yml               ← GitHub Pages auto-deploy
```

## npm scripts

| Command | What it does |
|---------|-------------|
| `npm run setup` | Install dependencies and VS Code extensions |
| `npm start` | Start local preview server |
| `npm run build` | Generate `dist/index.html` (static, offline) |
| `npm run check <module> <lesson>` | Run lesson grader |
| `npm run progress` | Show student progress summary |
| `npm run export` | Package course as a zip for VS Code distribution |
| `npm run submit` | Submit results to teacher API |

## Design principles

- **Teachers require Claude Code** — it generates and maintains the full course
- **Students need nothing by default** — static file works in any browser with no setup
- **VS Code adds interactivity** — checks, Claude clarifications, progress tracking
- **GitHub Pages adds reach** — one URL anyone can visit, auto-updated on push
- **Clarifications live in the course** — saved into `index.html` for all students, not scattered in chat
- **Offline-first** — the static build embeds everything; no CDN or server required after download
