Module 2 · Lesson 3

Variables Control Charts

Xbar-R and Xbar-S charts, control limits, Western Electric rules

Goal

Construct Xbar-R and Xbar-S control charts from subgroup data, compute control limits using the correct constants, and identify out-of-control signals.

Concept

A control chart is a time-series plot with three horizontal lines:

Centre Line (CL)

Process average

UCL

CL + 3σ

LCL

CL − 3σ

Points outside the UCL or LCL signal that the process is likely out of control — a special cause is present.

Xbar-R Chart (subgroup size n = 2–10)

Used for small subgroups. "R" is the within-subgroup range (max − min). Always plot two charts together: Xbar (location) and R (spread).

# Formulas

x̄̄ = mean of subgroup means

R̄ = mean of subgroup ranges

# Xbar chart limits

UCL = x̄̄ + A₂ × R̄

LCL = x̄̄ − A₂ × R̄

# R chart limits

UCL = D₄ × R̄

LCL = D₃ × R̄

Western Electric Out-of-Control Rules

  1. One point beyond 3σ limits
  2. Two of three consecutive points beyond 2σ on the same side
  3. Four of five consecutive points beyond 1σ on the same side
  4. Eight consecutive points on the same side of the centre line

Use Xbar-S instead of Xbar-R when subgroup size n > 10 — the standard deviation S is a more efficient estimator than the range R for larger samples.

For n=5: A₂=0.577, D₄=2.114

Xbar UCL = 500.17 + 0.577 × 2.10 = 501.38

Xbar LCL = 500.17 − 0.577 × 2.10 = 498.96

R UCL = 2.114 × 2.10 = 4.44

R LCL = 0

All points within limits → process is in control.
