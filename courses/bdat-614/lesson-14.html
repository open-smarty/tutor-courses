Module 6 · Lesson 14

Big Data Applications in SQC

EWMA, CUSUM, and Machine Learning integration

Goal

Implement EWMA and CUSUM charts in Python, explain why they outperform Shewhart charts for small sustained shifts, and describe how ML augments SQC in streaming environments.

Concept

Shewhart charts (Xbar-R, I-MR) detect large sudden shifts well. But they can miss small, sustained shifts — the type most common in Big Data processes. Two advanced charts address this:

EWMA — Exponentially Weighted Moving Average

Weights recent observations more heavily. Sensitive to gradual drift.

# EWMA statistic (λ = smoothing, 0 < λ ≤ 1)

EWMA₀ = μ₀

EWMAₜ = λ·xₜ + (1−λ)·EWMAₜ₋₁

# Control limits (asymptotically stable)

UCL = μ₀ + L·σ·√(λ/(2−λ))

LCL = μ₀ − L·σ·√(λ/(2−λ))

# Small λ (e.g. 0.1) → more smoothing → sensitive to small shifts

CUSUM — Cumulative Sum

Accumulates deviations from target. Detects a sustained 1σ shift in ~10 observations vs. 40+ for Shewhart.

# K = reference value (typically δ/2), H = decision interval (~4–5σ)

C⁺ₜ = max(0, C⁺ₜ₋₁ + (xₜ − μ₀ − K)) # upper CUSUM

C⁻ₜ = max(0, C⁻ₜ₋₁ − (xₜ − μ₀ − K)) # lower CUSUM

# Signal when C⁺ₜ > H or C⁻ₜ > H

ML Anomaly Model

Example — Server Response Time (λ=0.2)

Process: μ₀ = 250 ms, σ = 15 ms, L = 3, λ = 0.2

UCL = 250 + 3 × 15 × √(0.2/1.8)

= 250 + 3 × 15 × 0.333 = 265 ms

A sustained +10ms shift (250→260) is detected in ~6 observations by EWMA vs ~40 observations by Shewhart.
