Individuals and Moving Range (I-MR) Charts

n=1 observations, real-time Big Data monitoring

Goal

Construct an I-MR chart for individual observations, compute its control limits using E₂ and D₄, and explain why it is ideal for Big Data streaming scenarios.

Concept

Xbar-R requires subgroups of ≥ 2. Many real processes produce one observation at a time: daily server response times, one chemical batch per day, IoT sensor readings. For these, use the I-MR chart.

I-Chart (Individuals)

Plots each individual measurement xᵢ. Monitors process level.

MR-Chart (Moving Range)

Plots MRᵢ = |xᵢ − xᵢ₋₁|. Monitors process variability.

# Key formulas

x̄ = mean of all observations

MRᵢ = |xᵢ − xᵢ₋₁|

MR̄ = mean of all MRᵢ values

# I-Chart limits (E₂ = 2.66 for n=1)

UCL = x̄ + 2.66 × MR̄

LCL = x̄ − 2.66 × MR̄

# MR-Chart limits (D₄ = 3.267 for n=1)

UCL = 3.267 × MR̄

LCL = 0

Big Data: In streaming systems (Kafka, Spark Streaming), data arrives one point at a time. The I-MR chart evaluates each new observation immediately — enabling real-time quality monitoring without waiting to form subgroups.
