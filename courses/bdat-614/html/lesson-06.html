Module 3 · Lesson 6

Process Capability Analysis

Cp and Cpk indices — is the process meeting spec?

Goal

Compute Cp and Cpk from process data and specification limits, interpret the indices, and explain the difference between the two.

Concept

A control chart tells you if a process is statistically stable. But it doesn't tell you if it actually meets the customer's specification. That's what capability analysis answers.

USL

Upper Specification Limit

LSL

Lower Specification Limit

Cp — Potential Capability

Compares spec width to process spread. Assumes the process is centred.

Cp = (USL − LSL) / (6σ)

Cpk — Actual Capability (with centring)

Takes the smaller distance from the process mean to either spec limit.

Cpk = min( (USL − μ)/(3σ), (μ − LSL)/(3σ) )

Cpk ValueInterpretation
> 1.33Excellent — process comfortably fits inside spec
1.00 – 1.33Marginal — fits but with little room to spare
< 1.00Not capable — producing defects
Key insight: If Cp is much larger than Cpk, the process is capable but off-centred. Simply recentring the mean (without reducing variation) would immediately improve Cpk.
Cp = Cpk only when the process mean sits exactly between USL and LSL.
Important: Capability analysis is only valid after confirming the process is in statistical control. Never run Cp/Cpk on an unstable process.

Example — Shaft Diameter

LSL = 49.5 mm, USL = 50.5 mm. From 100 parts: μ = 50.1 mm, σ = 0.12 mm.

Cp = (50.5 − 49.5) / (6 × 0.12) = 1.0 / 0.72 = 1.39 ✓ Excellent potential

Cpk = min( (50.5−50.1)/(3×0.12), (50.1−49.5)/(3×0.12) )

= min( 1.11, 1.67 ) = 1.11 ⚠ Marginal

Cp > Cpk → mean shifted toward USL. Action: adjust mean to 50.0 mm.
