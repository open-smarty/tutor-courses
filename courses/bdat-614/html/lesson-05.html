Module 2 · Lesson 5

Attribute Control Charts

p, np, c, and u charts — counting defectives and defects

Goal

Select the correct attribute chart for a given situation, compute its control limits, and explain the difference between a defective and a defect.

Concept

When quality is measured by counting rather than measuring, use attribute charts. First, understand the distinction:

Defective (nonconforming unit)

An entire item passes or fails — binary. A transaction that errors out. A bottle with the wrong label.

Defect (nonconformity)

A specific flaw — one item can have multiple defects. Null values in a record. Scratches on a surface.

Chart Selection Guide

ChartWhat is CountedSample Size
p-chartProportion of defectivesVariable ✓
np-chartNumber of defectivesConstant only
c-chartNumber of defectsConstant only
u-chartDefects per unitVariable ✓

p-Chart Formulas (proportion defective, variable n)

p̄ = total defectives / total inspected

UCL = p̄ + 3 × √(p̄(1−p̄)/nᵢ) ← per sample

LCL = max(0, p̄ − 3 × √(p̄(1−p̄)/nᵢ))

u-Chart Formulas (defects per unit, variable n)

ū = total defects / total units inspected

UCL = ū + 3 × √(ū/nᵢ) ← per sample

LCL = max(0, ū − 3 × √(ū/nᵢ))

Both p and u charts use variable limits — the UCL and LCL change each period when nᵢ varies. np and c charts use constant limits when n is fixed.

Example — API Failure Monitoring (np-chart)

A web service samples 200 requests per hour (constant n=200). Failures per hour: 4, 6, 2, 8, 5, 3, 7, 4.

p̄ = 39/(8×200) = 0.0244

np̄ = 0.0244 × 200 = 4.875

UCL = 4.875 + 3 × √(4.875 × 0.9756) = 11.4

LCL = max(0, 4.875 − 6.54) = 0

Max failure count = 8 < 11.4 → process in control.
