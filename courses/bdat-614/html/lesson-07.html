Module 3 · Lesson 7

Measurement System Analysis

Gauge Repeatability and Reproducibility (R&R)

Goal

Explain what Gauge R&R measures, compute % GR&R, and determine whether a measurement system is acceptable for SPC or capability studies.

Concept

Before trusting any control chart or capability index, ask: can you trust the measurements themselves? A faulty gauge makes a good process look out of control and hides real problems.

Repeatability (EV)

Same operator, same part, same gauge — how consistent is the equipment?
"Can the gauge give consistent results?"

Reproducibility (AV)

Different operators, same part — how much do operators differ?
"Do different people get the same result?"

σ²_GaugeR&R = σ²_Repeatability + σ²_Reproducibility

TV = √(σ²_Process + σ²_GaugeR&R)

%GR&R = (σ_GaugeR&R / σ_Total) × 100

Acceptance Criteria

% GR&RInterpretation
< 10%Excellent — measurement system is adequate
10–30%Acceptable (depends on application)
> 30%Unacceptable — improve measurement system first!

Also check ndc (Number of Distinct Categories) ≥ 5. If ndc < 5, the gauge cannot reliably distinguish between parts.

Big Data angle: In streaming systems, sensors and APIs are the "gauge". A sensor with 38% GR&R contaminates every downstream model and dashboard — "garbage in, garbage out." Run MSA before building any analytics system.
