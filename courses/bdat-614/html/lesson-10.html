Module 5 · Lesson 10

Acceptance Sampling Plans

OC curves, AQL, LTPD, producer's and consumer's risk

Goal

Describe acceptance sampling, design a single sampling plan, compute an OC curve, and interpret producer's risk and consumer's risk.

Concept

Acceptance sampling decides whether to accept or reject a lot (batch) of products by inspecting a sample. Used when 100% inspection is too expensive or destructive.

Acceptance sampling is not a substitute for SPC — it does not improve the process. It only makes accept/reject decisions.

Key Terms

TermMeaning
NLot size
nSample size
cAcceptance number — max defectives allowed in sample
AQLAcceptable Quality Level — producer's good quality level
LTPDLot Tolerance Percent Defective — consumer's bad quality level
αProducer's risk — P(rejecting a good lot) — Type I error
βConsumer's risk — P(accepting a bad lot) — Type II error

Single Sampling Plan Decision Rule

# Inspect n items. Count defectives d.

if d <= c: ACCEPT the lot

if d > c: REJECT the lot

OC Curve

Plots Pa (probability of accepting the lot) vs. p (true proportion defective). Uses the Binomial distribution:

Pa(p) = P(X ≤ c | X ~ Binomial(n, p))

# In Python: scipy.stats.binom.cdf(c, n, p)

A steeper OC curve means the plan discriminates better between good and bad lots.

Example — N=2000, n=125, c=3

At p=0.01 (AQL): Pa = P(X≤3 | Binom(125,0.01)) ≈ 0.97 α ≈ 3%

At p=0.05 (LTPD): Pa = P(X≤3 | Binom(125,0.05)) ≈ 0.10 β ≈ 10%

Good lots (p=1%) are accepted 97% of the time. Bad lots (p=5%) are rejected 90% of the time.
