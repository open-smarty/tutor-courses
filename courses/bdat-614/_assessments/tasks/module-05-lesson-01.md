# Task: Module 5, Lesson 1 — Sampling Plan Comparison

## Objective

Compare two different single sampling plans and recommend which is better for a given situation.

## Scenario

A medical device company receives shipments of electronic components from a supplier. Defective components can cause patient safety issues, so the consumer's risk must be kept very low (β ≤ 5%). The AQL is set at 1%.

Two sampling plans are proposed:
- **Plan A:** n=50, c=1
- **Plan B:** n=200, c=4

## Instructions

1. For both plans, use Python to compute and plot the OC curve on the same figure.

2. Compute and compare:
   - Pa at AQL = 1%
   - Pa at LTPD = 5%
   - Producer's risk (α) for each plan
   - Consumer's risk (β) for each plan

3. Determine which plan meets the β ≤ 5% requirement.

4. Write a recommendation (as print output) explaining:
   - Which plan you recommend and why.
   - What the trade-off is in terms of inspection cost.
   - Whether the producer's risk is acceptable for both plans.

## Criteria

- Both OC curves computed and plotted correctly: 35%
- Producer's and consumer's risks calculated for both plans: 30%
- Correct plan identified for the β requirement: 20%
- Recommendation is clear and addresses trade-offs: 15%
