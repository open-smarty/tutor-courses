# Task: Module 5, Lesson 2 — Six Sigma DMAIC Project Proposal

## Objective

Design a Six Sigma improvement project from scratch, including DPMO baseline, sigma level, and a full DMAIC outline.

## Scenario

You are a Green Belt at a logistics company. The package delivery system has a damage rate of 8 damaged packages per 1,000 deliveries. Each delivery has 6 potential failure points (loading, transit, unloading, sorting, last-mile, handoff).

## Instructions

1. Compute the current DPMO and sigma level.

2. The company's target is 5σ. Compute:
   - How many fewer damaged packages per 1,000 deliveries are needed?
   - What is the target damage rate as a percentage?

3. Write a DMAIC project outline (as printed text or Python comments):
   - **Define:** Project scope, objectives, team, and financial impact estimate.
   - **Measure:** What data would you collect? What control chart would you use?
   - **Analyze:** Which 6M categories are most likely? What tool would you use first?
   - **Improve:** Propose one change to test (be specific — not just "improve loading").
   - **Control:** What chart and process would you use to sustain the improvement?

4. Python computation: write the DPMO and target calculations in a `task_six_sigma.py` file with print output.

## Criteria

- DPMO and sigma level computed correctly: 30%
- Target DPMO and damage reduction computed correctly: 20%
- DMAIC outline is specific and actionable: 35%
- Code produces correct printed output: 15%
