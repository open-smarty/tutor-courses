Process Variation — Sources and Types

Common cause vs special cause, 6Ms, 5 Whys

Goal

Distinguish between common-cause and special-cause variation, identify the 6M sources of variation, and apply the 5 Whys technique to find a root cause.

Concept

Every process has variation. A machine that fills bottles never fills exactly 500 ml each time. The critical question is: what kind of variation is it?

Common-Cause Variation

  • Always present — due to many small unknown factors
  • Predictable — process is "in control"
  • Can only be reduced by changing the process (management decision)

Special-Cause Variation

  • Caused by a specific, identifiable event
  • Unpredictable — process is "out of control"
  • Must be found and fixed immediately

Analogy: A river's water level rises and falls with seasons — common cause. A dam bursting upstream is a special cause — identifiable, unusual, must be addressed immediately.

The 5 Whys

Ask "why?" five times in sequence. Each answer prompts the next "why?" until you reach the true root cause.

Problem: Defective parts increase suddenly.
Why 1? The cutting tool is worn.
Why 2? Maintenance schedule was skipped.
Why 3? The maintenance log system went offline.
Why 4? A server update deleted the cron job.
Root cause: No version-controlled backup of scheduled maintenance jobs.

Example — ETL Pipeline

A pipeline that normally runs in 45 minutes suddenly takes 3 hours.

  • Special cause: a new data source added with 50× more records than expected.
  • 6M source: Material (data volume).
  • Root cause (5 Whys): no data source onboarding protocol — volume was never checked before adding.
  • Actions: fix the immediate issue (partition the load) and address the root cause (implement an onboarding checklist).
