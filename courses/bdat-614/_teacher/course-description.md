# Course Description

**Course title:** Statistical Quality Control and Improvement (BDAT 614)

**Subject area:** Statistics / Data Analytics / Quality Engineering

**Target audience:** MSc Big Data Analytics students; assumes basic statistics and introductory Python

**Approximate duration:** 14 lessons across 6 modules (~35 hours)

## Overview

This course provides a comprehensive introduction to statistical quality control (SQC) and continuous improvement. Students learn to apply classical statistical methods — control charts, capability analysis, acceptance sampling — as well as modern quality frameworks like Six Sigma/DMAIC and TQM.

A distinctive feature of this course is its Big Data orientation. Every topic is connected to modern data engineering contexts: real-time streaming SPC using Kafka/Spark, Python-based control charts, anomaly detection in ETL pipelines, and predictive quality analytics using machine learning.

The course is structured in six modules progressing from foundations to applied Big Data SQC. Each module contains 2–3 lessons with Python exercises, quizzes, and applied tasks.

## Topics covered

- What is Quality? Definitions, dimensions, QC vs QA, ISO 9001
- Process variation: common cause, special cause, sources (6Ms)
- Statistical Process Control: Xbar-R, Xbar-S, I-MR, p, np, c, u charts
- Process Capability Analysis: Cp, Cpk indices
- Measurement System Analysis: Gauge R&R (repeatability & reproducibility)
- Continuous improvement: Shewhart Cycle (PDCA/PDSA), DMAIC framework
- Root cause analysis: Fishbone diagram, Pareto chart, 5 Whys
- Acceptance Sampling: single/double plans, OC curves, AQL, LTPD
- Six Sigma and Lean Six Sigma: DPMO, performance levels, Lean tools
- Total Quality Management (TQM): Deming's 14 Points, COPQ
- Big Data applications: EWMA, CUSUM, ML + SPC, real-time quality monitoring
