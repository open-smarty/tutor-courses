# Learning Requirements

## Learning outcomes

After completing this course, students will be able to:

1. Explain the principles of statistical quality control and distinguish between common-cause and special-cause variation.
2. Construct and interpret Xbar-R, Xbar-S, I-MR, p, np, c, and u control charts using Python.
3. Perform process capability analysis using Cp and Cpk and interpret results in context.
4. Conduct a Measurement System Analysis (Gauge R&R) and assess whether a measurement system is adequate.
5. Apply the DMAIC framework and Shewhart Cycle to structure quality improvement projects.
6. Design single sampling plans, evaluate OC curves, and balance producer vs. consumer risk.
7. Describe Six Sigma performance levels and apply Lean Six Sigma tools.
8. Articulate TQM principles, Deming's 14 Points, and the four categories of Cost of Poor Quality.
9. Implement SQC methods in Big Data contexts using Python (EWMA, CUSUM, real-time simulation).

## Prerequisites

- Basic statistics: mean, variance, normal distribution, basic hypothesis testing
- Introductory Python: variables, loops, functions, numpy/matplotlib basics
- No prior quality control experience required

## Constraints

- All exercises are Python-based (.py files) — students should use Python 3.8+ with numpy, scipy, matplotlib, pandas
- Each lesson builds on prior ones; do not skip modules
- Exercises use realistic datasets drawn from manufacturing, IoT sensor, and data pipeline scenarios
- Solutions are teacher references; visible after passing the quiz for a lesson

## Structure

- Modules: 6
- Lessons per module: 2–3
- Total lessons: 14
