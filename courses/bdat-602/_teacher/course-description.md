# Course Description

**Course title:** BDAT 602: Data Mining and Applications

**Subject area:** Data Mining / Machine Learning / R Programming

**Target audience:** MSc Big Data Analytics students (University of Ghana, Legon); assumes prior R literacy, basic statistics, and familiarity with dplyr and ggplot2

**Approximate duration:** ~8 hours across 14 lessons (6 modules)

**Department:** Statistics & Actuarial Science, University of Ghana, Legon
**Academic Year:** 2025/2026

## Overview

This course introduces data mining as the systematic extraction of patterns, anomalies, and actionable insights from large datasets. Students learn the full pipeline from raw data to deployed knowledge, following both the KDD process and CRISP-DM framework. The six-module arc mirrors the six data mining tasks supported by the course dataset: a 500,000-row simulated global health insurance portfolio with intentional quality issues, association structure, clustering signal, classification targets, and free-text complaints.

The unifying dataset — generated by `simulate_bdat602()` — provides a consistent thread across all six mining tasks. Students encounter the same 40-variable portfolio as they progress from cleaning it (Module 2) to mining association rules among add-on covers (Module 3), segmenting policyholders into clusters (Module 4), building classification models for churn and fraud (Module 5), and extracting topics from complaint notes (Module 6).

The course uses R throughout, with `tidymodels` and `recipes` as the preprocessing framework, `arules` / `arulesViz` for association mining, `rpart` and `randomForest` for classification, `tidytext` and `topicmodels` for text mining, and `sparklyr` for at-scale Spark operations.

## Topics covered

- Data mining tasks: classification, regression, clustering, association rules, anomaly detection, text mining
- The 4 Vs of Big Data (Volume, Velocity, Variety, Veracity)
- KDD process and CRISP-DM framework
- Reading large files with `readr::read_csv()` and `data.table::fread()`; `skimr::skim()` for first-pass EDA
- Pushing computation to Apache Spark via `sparklyr`
- Missing value mechanisms (MCAR, MAR, MNAR); median, mode, and kNN imputation with `recipes`
- Outlier detection (IQR rule, Z-score, box plots); winsorisation and log transformation
- Feature scaling: Z-score, Min-Max, Robust scaling
- Categorical encoding: one-hot / dummy coding, ordinal integer encoding
- Leak-proof preprocessing pipeline: `recipe()` → `prep()` → `bake()`
- Association rule mining: support, confidence, lift; Apriori with `arules`; visualisation with `arulesViz`
- k-Means clustering: choosing k (elbow and silhouette), cluster profiling
- Hierarchical clustering: linkage methods, dendrograms, `hclust()` and `cutree()`
- PCA for dimensionality reduction and cluster visualisation
- Decision trees: `rpart`, `rpart.plot`, pruning, Gini impurity
- Random forests: `randomForest`, variable importance, out-of-bag error
- Class imbalance: SMOTE, oversampling, class weights, threshold adjustment with `themis`
- Text mining: tokenisation, TF-IDF, document-term matrices with `tidytext`
- Topic modelling: Latent Dirichlet Allocation (LDA) with `topicmodels`
