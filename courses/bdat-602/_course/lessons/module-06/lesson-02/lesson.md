## Concept

### What Is Topic Modelling?

Topic modelling discovers **latent themes** in a corpus without using predefined labels. Each document is assumed to be a mixture of topics; each topic is a distribution over words.

**Latent Dirichlet Allocation (LDA):**
- $k$ topics are specified in advance
- Each document is a mixture of all $k$ topics (some proportions may be near zero)
- Each topic is a probability distribution over the vocabulary
- LDA learns both distributions simultaneously via expectation-maximisation

---

### LDA in R with topicmodels

```r
library(topicmodels)
library(tidytext)
library(dplyr)
library(ggplot2)
source("R/simulate_bdat602_data.R")

health_small <- simulate_bdat602(n = 10000, seed = 602)

# Build DTM (as in Lesson 1)
data("stop_words")
complaints <- health_small |>
  filter(!is.na(complaint_notes)) |>
  mutate(doc_id = row_number())

dtm <- complaints |>
  unnest_tokens(word, complaint_notes) |>
  anti_join(stop_words, by = "word") |>
  filter(nchar(word) > 2) |>
  count(doc_id, word) |>
  cast_dtm(document = doc_id, term = word, value = n)

# Fit LDA with k = 5 topics
set.seed(602)
lda_fit <- LDA(dtm, k = 5, control = list(seed = 602))
```

---

### The Beta Matrix — Word–Topic Probabilities

`beta` gives the probability of each word being generated by each topic:

```r
beta_mat <- tidy(lda_fit, matrix = "beta")

# Top 8 words per topic
beta_mat |>
  group_by(topic) |>
  slice_max(beta, n = 8) |>
  ungroup() |>
  ggplot(aes(x = reorder(term, beta), y = beta,
             fill = factor(topic))) +
  geom_col(show.legend = FALSE) +
  facet_wrap(~ topic, scales = "free_y") +
  coord_flip() +
  labs(title = "LDA Top Words per Topic",
       x = NULL, y = "Beta (word probability)") +
  theme_minimal()
```

---

### The Gamma Matrix — Document–Topic Probabilities

`gamma` gives the proportion of each document attributed to each topic:

```r
gamma_mat <- tidy(lda_fit, matrix = "gamma")

# Average gamma per topic = relative topic prevalence
gamma_mat |>
  group_by(topic) |>
  summarise(avg_gamma = mean(gamma)) |>
  ggplot(aes(x = factor(topic), y = avg_gamma,
             fill = factor(topic))) +
  geom_col(show.legend = FALSE) +
  labs(title = "Average Topic Prevalence in Complaints",
       x = "Topic", y = "Average Gamma") +
  theme_minimal()
```

### Joining Topics Back to the Original Data

```r
dominant_topic <- gamma_mat |>
  group_by(document) |>
  slice_max(gamma, n = 1) |>
  ungroup() |>
  mutate(doc_id = as.integer(document))

complaints_labeled <- complaints |>
  left_join(dominant_topic |> select(doc_id, topic),
            by = "doc_id")

# Churn rate per complaint topic
complaints_labeled |>
  group_by(topic) |>
  summarise(churn_rate = round(mean(churned) * 100, 2), n = n()) |>
  arrange(desc(churn_rate))
```

Topics related to billing disputes and service failures typically correlate with higher churn — actionable insight for the insurer's retention team.
