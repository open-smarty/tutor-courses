# Task: CRISP-DM Project Plan

## Objective

Apply the CRISP-DM framework to plan a real data mining project using the health insurance dataset.

## Instructions

Choose **one** of the following business problems:

- **Option A:** Predict which policyholders are at risk of churning in the next 3 months
- **Option B:** Identify fraudulent claims in the incoming daily batch

In your exercise Rmd, add a new markdown section titled "## CRISP-DM Project Plan". Write 2–3 sentences for each of the six phases:

1. **Business Understanding** — What is the business problem? What does success look like (define the KPI)?
2. **Data Understanding** — Which variables in the dataset are most relevant? What quality issues did you observe in the EDA?
3. **Data Preparation** — Which cleaning steps are required? Which variables need encoding or transformation?
4. **Modelling** — Which algorithm(s) would you consider? Why?
5. **Evaluation** — Which metric(s) will you use? Why is accuracy alone insufficient?
6. **Deployment** — How would the model be used in practice? At what frequency?

## Submission

Knit your Rmd to HTML. The CRISP-DM section should be clearly visible as formatted markdown.
